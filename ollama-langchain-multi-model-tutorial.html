LESSON 01 / 13

Start here

Goal: use the same LangChain interface to call different local models, pass answers between them, and combine embeddings with chat.

A beginner lab with five small console examples. Python 3.10+ (3.11 recommended), Ollama and the models listed below are required. There is no cloud API key, vector database, web server, LangGraph or LangSmith requirement. Installing Python dependencies needs internet access; inference uses your configured Ollama server.

Think of Ollama as the model server and LangChain as the Python toolkit that formats prompts and connects stages. Multiple models can mean comparing independent answers, chaining stages, or choosing one model for a task.

Every model receives the same question. Calls run one at a time. Output contains a model heading, answer and elapsed seconds for each. Timings include loading and are demonstrations, not controlled benchmarks. A failed call is reported and the loop tries the remaining models, then exits with an error status if any failed.

python
"""Lesson 2: send the same prompt to multiple models, sequentially."""
import argparse
from time import perf_counter
from common import CHAT_MODELS, add_settings, make_chat, require_models, run_cli, text_content


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    add_settings(parser)
    parser.add_argument("--models", nargs="+", choices=CHAT_MODELS,
                        default=["llama3.2:1b", "phi3:latest"])
    parser.add_argument("--question", default="Explain DNS using a simple real-world example.")
    args = parser.parse_args()
    require_models(args.base_url, args.models)
    failures = []
    for name in args.models:
        print(f"\n--- {name} ---", flush=True)
        started = perf_counter()
        try:
            result = make_chat(name, args).invoke([
                ("system", "Answer in no more than five short sentences."),
                ("human", args.question),
            ])
            print(text_content(result))
            print(f"Elapsed seconds: {perf_counter() - started:.2f}")
        except Exception as error:
            failures.append(name)
            print(f"FAILED: {error}")
    if failures:
        print("\nFailed models:", ", ".join(failures))
        raise SystemExit(1)


if __name__ == "__main__":
    run_cli(main)

Writer → reviewer

powershell
.\.venv\Scripts\python.exe 03_two_model_pipeline.py --topic "Explain async and await in C#"
.\.venv\Scripts\python.exe 03_two_model_pipeline.py --writer llama3.2:latest --reviewer phi3:latest --topic "Explain database indexing"

llama3.2:1b drafts by default. Its output becomes an input to phi3:latest, which rewrites it. Each stage is a LangChain expression: prompt | model | StrOutputParser(). This is a two-stage workflow; the reviewer can still make mistakes. Confirm technical claims yourself.

Read the complete 03_two_model_pipeline.py
python
"""Lesson 3: one model drafts; a second model rewrites the draft."""
import argparse
from common import CHAT_MODELS, add_settings, make_chat, require_models, run_cli


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    add_settings(parser)
    parser.add_argument("--writer", choices=CHAT_MODELS, default="llama3.2:1b")
    parser.add_argument("--reviewer", choices=CHAT_MODELS, default="phi3:latest")
    parser.add_argument("--topic", default="What is a REST API?")
    args = parser.parse_args()
    from langchain_core.output_parsers import StrOutputParser
    from langchain_core.prompts import ChatPromptTemplate
    require_models(args.base_url, [args.writer, args.reviewer])

    draft_prompt = ChatPromptTemplate.from_messages([
        ("system", "Write a concise beginner explanation in at most 100 words."),
        ("human", "Topic: {topic}"),
    ])
    review_prompt = ChatPromptTemplate.from_messages([
        ("system", "Rewrite the draft clearly in at most 100 words. Correct obvious "
                   "technical mistakes. Return only the revised explanation."),
        ("human", "Original topic: {topic}\nDraft:\n{draft}"),
    ])
    writer_chain = draft_prompt | make_chat(args.writer, args) | StrOutputParser()
    reviewer_chain = review_prompt | make_chat(args.reviewer, args) | StrOutputParser()

    print("Draft model:", args.writer, flush=True)
    draft = writer_chain.invoke({"topic": args.topic})
    if not draft.strip():
        raise RuntimeError("Writer returned an empty draft. Increase --max-tokens.")
    print(draft)
    print("\nReview model:", args.reviewer, flush=True)
    revised = reviewer_chain.invoke({"topic": args.topic, "draft": draft})
    if not revised.strip():
        raise RuntimeError("Reviewer returned an empty answer. Increase --max-tokens.")
    print(revised)


if __name__ == "__main__":
    run_cli(main)

LESSON 09 / 13

Embeddings + chat: mini RAG

powershell
.\.venv\Scripts\python.exe 05_embeddings_rag.py
.\.venv\Scripts\python.exe 05_embeddings_rag.py --model phi3:latest --question "What should I do if my laptop breaks?" --top-k 1

The three fictional company policies live in data/policies.json:

  1. OllamaEmbeddings sends document text to nomic-embed-text:latest and receives numeric vectors.
  2. It embeds the question with the same embedding model.
  3. Python cosine similarity ranks the documents; the best --top-k excerpts form the context.
  4. ChatOllama sends that context and question to your chosen chat model.
  5. The script prints retrieved evidence, generated answer and retrieved source IDs.

For the default question, the intended evidence is production-access-v1: approval comes from the manager and platform operations; access lasts 24 hours. This is sample policy data, not real company guidance. Retrieval is semantic and can choose the wrong excerpt; inspect the printed evidence. Retrieved source IDs describe the evidence supplied, not verified model citations. The tiny lab rebuilds all vectors on each run, stores them in memory, and uses no vector database. search_document: and search_query: distinguish the document/query embedding tasks. Do not change embedding models for just one side: both vectors must share the same embedding space.

Read the complete 05_embeddings_rag.py
python
"""Lesson 5: nomic embeddings retrieve evidence; a chat model answers."""
import argparse
import json
from pathlib import Path
from common import (
    CHAT_MODELS, EMBEDDING_MODEL, add_settings, cosine_similarity,
    make_chat, positive_int, require_models, run_cli, text_content,
)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    add_settings(parser)
    parser.add_argument("--model", choices=CHAT_MODELS, default="llama3.2:1b")
    parser.add_argument("--question", default="Who approves production access and how long does it last?")
    parser.add_argument("--top-k", type=positive_int, default=1)
    args = parser.parse_args()
    from langchain_ollama import OllamaEmbeddings
    require_models(args.base_url, [EMBEDDING_MODEL, args.model])

    path = Path(__file__).resolve().parent / "data" / "policies.json"
    documents = json.loads(path.read_text(encoding="utf-8"))
    if not documents:
        raise ValueError("The policy file has no documents.")
    embedder = OllamaEmbeddings(
        model=EMBEDDING_MODEL, base_url=args.base_url,
        client_kwargs={"timeout": args.timeout, "trust_env": False},
    )
    print("Embedding model:", EMBEDDING_MODEL, flush=True)
    vectors = embedder.embed_documents([
        "search_document: " + doc["text"] for doc in documents
    ])
    query_vector = embedder.embed_query("search_query: " + args.question)
    if len(vectors) != len(documents):
        raise ValueError("Embedding result count does not match the document count.")
    ranked = sorted(
        [(cosine_similarity(query_vector, vector), doc)
         for vector, doc in zip(vectors, documents)],
        key=lambda pair: pair[0], reverse=True,
    )[:args.top_k]
    print("\nRetrieved evidence:")
    for score, doc in ranked:
        print(f"{doc['id']} | cosine={score:.3f}")
        print(doc["text"])
    context = "\n\n".join(f"[{doc['id']}] {doc['text']}" for _, doc in ranked)
    print("\nAnswer model:", args.model, flush=True)
    response = make_chat(args.model, args).invoke([
        ("system", "Answer only from the supplied policy excerpts. If the excerpts "
                   "do not answer the question, say that evidence is missing. "
                   "Keep the answer under 100 words."),
        ("human", f"Question: {args.question}\n\nPolicy excerpts:\n{context}"),
    ])
    print(text_content(response))
    print("Retrieved source IDs:", ", ".join(doc["id"] for _, doc in ranked))


if __name__ == "__main__":
    run_cli(main)

LESSON 10 / 13

Understand the LangChain code

  • base_url: Ollama HTTP endpoint, normally http://127.0.0.1:11434.
  • temperature=0.2: requests less variable responses; does not promise identical output.
  • num_ctx=2048: small context setting for this short lab.
  • num_predict: maximum generated token budget; set with --max-tokens.
  • keep_alive=0: asks Ollama to unload a chat model after a response, reducing resident model memory but adding reload time. The embedding client's default residency can differ.
  • reasoning=False: used for qwen3:8b to request a direct answer instead of a thinking phase; requires a compatible Ollama/model version.
  • client_kwargs: timeout and disabled inherited proxy settings for the configured connection.
  • require_models: checks /api/tags before generation and reports missing exact tags.
  • invoke: performs a blocking model call and returns an AI message. text_content extracts the answer text.
  • prompt | model | parser: LangChain's runnable composition, often called LCEL. The parser returns a string.

--timeout defaults to 240 seconds; it is a client operation timeout, not a strict total workflow deadline. --max-tokens defaults to 384. Most examples support these shared options:

powershell
.\.venv\Scripts\python.exe 01_single_model.py --model phi3:latest --timeout 600 --max-tokens 512 --base-url http://127.0.0.1:11434

Set OLLAMA_BASE_URL to change the default server URL. Prefer loopback for this lab. Using a remote URL sends the prompts and policy excerpts to that server.

Read common.py
python
"""Small shared settings and Ollama connection checks for the five demos."""
import argparse
import json
import math
import os
from urllib.error import HTTPError, URLError
from urllib.request import ProxyHandler, Request, build_opener

CHAT_MODELS = (
    "llama3.2:1b",
    "phi3:latest",
    "llama3.2:latest",
    "qwen3:8b",
)
EMBEDDING_MODEL = "nomic-embed-text:latest"


def positive_int(value):
    number = int(value)
    if number <= 0:
        raise argparse.ArgumentTypeError("Use a positive integer.")
    return number


def add_settings(parser):
    parser.add_argument(
        "--base-url", default=os.getenv("OLLAMA_BASE_URL", "http://127.0.0.1:11434"),
        help="Ollama server URL. Default: http://127.0.0.1:11434",
    )
    parser.add_argument("--timeout", type=positive_int, default=240,
                        help="Client operation timeout in seconds. Default: 240")
    parser.add_argument("--max-tokens", type=positive_int, default=384,
                        help="Maximum generated tokens. Default: 384")


def installed_models(base_url):
    """Inspect an already-running Ollama server; never download a model."""
    url = base_url.rstrip("/") + "/api/tags"
    request = Request(url, headers={"Accept": "application/json"})
    # Local inference should not inherit a corporate HTTP proxy.
    opener = build_opener(ProxyHandler({}))
    try:
        with opener.open(request, timeout=10) as response:
            data = json.load(response)
    except (HTTPError, URLError, TimeoutError, OSError) as error:
        raise RuntimeError(
            f"Cannot reach Ollama at {base_url}. Open Ollama, or run 'ollama serve' "
            "if no server is already running. Check --base-url."
        ) from error
    names = [item.get("name") or item.get("model")
             for item in data.get("models", [])]
    return sorted({name for name in names if isinstance(name, str)})


def require_models(base_url, wanted):
    installed = installed_models(base_url)
    missing = sorted(set(wanted) - set(installed))
    if missing:
        raise RuntimeError(
            "Missing exact model tag(s): " + ", ".join(missing)
            + ". Run 'ollama list' and choose an installed tag."
        )


def make_chat(model, args):
    if model not in CHAT_MODELS:
        raise ValueError("Choose a chat model from CHAT_MODELS.")
    from langchain_ollama import ChatOllama

    settings = {
        "model": model,
        "base_url": args.base_url,
        "temperature": 0.2,
        "num_ctx": 2048,
        "num_predict": args.max_tokens,
        "keep_alive": 0,
        "client_kwargs": {"timeout": args.timeout, "trust_env": False},
    }
    if model == "qwen3:8b":
        settings["reasoning"] = False
    return ChatOllama(**settings)


def text_content(message):
    """Handle either text content or standard text content blocks."""
    content = message.content
    if isinstance(content, str):
        text = content
    elif isinstance(content, list):
        text = "\n".join(
            block if isinstance(block, str) else block.get("text", "")
            for block in content if isinstance(block, (str, dict))
        )
    else:
        text = ""
    if not text.strip():
        raise RuntimeError(
            "The model returned no answer text. Increase --max-tokens and check "
            "the model's thinking settings and Ollama version."
        )
    return text.strip()


def cosine_similarity(left, right):
    if not left or len(left) != len(right):
        raise ValueError("Embedding vectors must have equal, nonzero dimensions.")
    dot = sum(a * b for a, b in zip(left, right))
    magnitude = math.sqrt(sum(x * x for x in left) * sum(x * x for x in right))
    if magnitude == 0:
        raise ValueError("Cannot compare a zero-length embedding vector.")
    return dot / magnitude


def run_cli(main):
    try:
        main()
    except KeyboardInterrupt:
        print("\nStopped by user.")
        raise SystemExit(130)
    except Exception as error:
        print(f"ERROR: {error}")
        print("Check the README troubleshooting section.")
        raise SystemExit(1)

Troubleshooting and memory

SymptomAction
Cannot reach OllamaOpen Ollama or start ollama serve if no instance is running; check --base-url.
Missing exact model tagRun ollama list; choose one of your listed tags.
No module named langchain_ollamaRun the dependency installation with the same virtual-environment Python used for the scripts.
Slow first responseModel loading takes time. Start with llama3.2:1b; increase --timeout if needed.
RAM pressure or model load errorClose other model sessions, inspect ollama ps, use the 1b model, and avoid simultaneous heavy calls. You can stop a loaded model with ollama stop MODEL_TAG.
Empty or truncated answerIncrease --max-tokens; for Qwen check thinking support and update Ollama if needed.
Qwen thinking-setting errorCheck the current Ollama thinking documentation and installed model version; use phi3:latest to continue the lab.
Unexpected policy answerInspect retrieved evidence, rephrase the query, or try --top-k 2; ranking is not guaranteed.
Port already in useCheck whether Ollama is already running; do not start duplicate servers.

Practice and check your understanding

  1. Ask the same C# question to all four chat models. Compare correctness manually.

  3. Change the detailed task route in 04_route_models.py to llama3.2:latest.

Can nomic-embed-text answer a chat question?

No. It produces numeric vectors. Use a chat model to generate an answer.

Does Lesson 2 run all models at once?

No. It calls models sequentially. This helps limit simultaneous chat-model memory use.

Does the reviewer guarantee correctness?

No. It rewrites a draft but can still invent or preserve errors.

What does the pipe operator do here?

It connects LangChain runnable stages: prompt, model, and string output parser.

Why use the same embedding model for the query and documents?

Their vectors must belong to the same embedding space so similarity comparisons are meaningful.
